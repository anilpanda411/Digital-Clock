# 🎨 Customization

## Change Glow Color

Inside `style.css`:

```css
--glow-color: #7aa2f7;
```

Replace with any color you like.

---

## Change Background Colors

Edit gradient variables:

```css
--bg1
--bg2
--bg3
--bg4
```

---

## Change Animation Speed

Example:

```css
animation: float 5s ease-in-out infinite;
```

Change `5s` to:
- `2s` → faster
- `8s` → slower
